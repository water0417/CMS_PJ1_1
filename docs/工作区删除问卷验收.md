# 工作区删除问卷

每份问卷卡片的操作区新增“删除”，支持草稿、收集中和已关闭问卷。确认框显示标题、已有答卷数，并说明填写链接失效及数据保留。取消不发删除请求；成功后立即更新工作区、侧栏数量和分页；版本冲突刷新列表并要求重新确认，不自动删除新版本。

后端 `DELETE /api/surveys/:id`，请求 `{ revision }`。使用 ownerId、revision、deletedAt 原子检查并写入软删除标记。仅本人可操作，缺少版本号拒绝，旧版本冲突返回 409。软删除后列表、编辑、统计、路由信息、公开链接、旧填写的查看／推进／提交均不再可用。原问卷、发布版本、答卷和占位数据保留在数据库，本次未增加回收站或恢复界面。

本次修改：`apps/api/src/database.ts`、`apps/api/src/service.ts`、`apps/api/src/main.ts`、`apps/web/src/workspace.ts`、`apps/web/src/pages/Dashboard.vue`、`tests/integration.ts`、`docs/API说明.md`、本文档。

实际验证：前后端构建通过；真实独立 MongoDB 测试库 28/28 组集成测试通过，含新增删除权限、未登录、非法版本号、冲突、重复删除、三种状态、原链接／填写／统计不可用及原始数据保留检查。浏览器在独立库创建专用草稿，验证取消、确认、卡片移除、数量由 28 变 27、草稿数由 3 变 2、分页由 10 页变 9 页及刷新后仍然隐藏。未删除任何正式问卷。

证据：`test-results/workspace-delete-integration.txt`、`test-results/workspace-delete-integration.json`；截图 `design-preview/migrated/workspace-delete-confirm.png` 和 `workspace-delete.png`。本轮未进行移动端和多浏览器专项验收。
