## 4. 发现的问题和修正

1. 首次类型构建发现 Mongoose 通用模型的类型推断不正确及 Vue 回调隐式 any，已修正。
2. 首次集成测试等待服务启动不足，延长等待窗口，不改变业务逻辑。
3. 集合验证拒绝初始填写：Mongoose 默认省略空对象，导致 state.answers 缺失。设置 minimize:false 后复测通过。
4. 编辑器不能直接 structuredClone Vue 响应式代理，改为对纯JSON定义进行序列化复制。
5. 本机旧版 Node 24.3 在前端构建时出现 Windows 异常退出（3221226505）；同源码使用较新运行时可构建。项目增加本地 Node 22 LTS 依赖，由 npm 脚本使用并以锁文件固定，不改全局环境。最终完整构建已通过。

| 用例组        | 输入与步骤                                                       | 预期/实际                                                                              |
