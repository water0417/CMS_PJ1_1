# 前端迁移验收 · 2026-10-22

## 已迁移

保留用户确认的灰阶杂志设计、自绘 SVG 刊头、三极花朝体·粗主标题及微软雅黑辅助文字，迁移到正式 Vue 项目。登录/注册、工作台、编辑、填写、统计共五类页面使用同一外框与灰阶组件。

工作台每页三份真实问卷，搜索、草稿箱、状态筛选和分页可用。少于三份时显示新建入口，不补假问卷。新建草稿及三种模板都写入现有后端。题数和成功答卷数由 MongoDB 返回，分享链接指向正式填写路由。

编辑、填写和统计允许在固定应用窗口内滚动，避免裁切长问卷与矩阵表格。工作台无需页面滚动：浏览器验证 1280×720、390×844，文档宽高与视口一致。手机分享/统计链接位于视口内，顶部有新建入口。

## 实际浏览器流程

写入操作使用 survey_studio_test_1792649101639 独立测试数据库，通过临时 3102 端口完成，未向正式问卷写入验收数据：

1. owner 登录并查看真实问卷分页，1/2 → 2/2。
2. 模板中心选择“活动体验反馈”，创建包含评分、单选、文本的三题草稿。
3. 改名为“界面验收 · 活动体验反馈”，保存后发布，验证发布内容锁定。
4. 复制填写链接；通过编辑器“打开填写页”进入真实填写。
5. 选择评分 4，进入下一题；刷新后点击继续上次填写，恢复至第二题。
6. 单选选择“愿意”，文本填写迁移验收说明，提交成功。
7. 统计页显示 1 份成功答卷、3 道题、平均/最小/最大评分 4；“愿意”为 100%；填写内容查询返回提交文本。
8. 正式 3000 服务用 demo 登录，读取现有 2 份问卷、9 道题发布问卷及其 9 份历史答卷，未修改这些业务数据。
