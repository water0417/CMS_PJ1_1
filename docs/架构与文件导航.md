# 架构与文件导航

## 运行结构

浏览器 Vue SPA → /api HTTP＋Cookie → NestJS 控制器 → 应用服务 → 领域引擎／Mongoose → MongoDB 副本集。正式构建由同一后端托管 web/dist 并处理 SPA 深链接；开发时 Vite 代理 API。

领域引擎是路径语义的唯一来源。前端复用分类契约用于未保存编辑预览，实际填写始终使用服务端游标与路径，不自行导航。不存在独立显示条件设置。

## 数据边界与演化

users、sessions、auth_throttles 管理账号、会话及认证节流；surveys 保存所有者、草稿和发布指针；survey_versions 保存不可变定义；response_attempts 保存游标、确认状态、候选区和推进次数；responses 保存有效正式答卷；submission_claims 防止限次并发提交。

问卷题目内嵌在定义中便于整体发布和校验；答卷独立集合避免问卷文档无限增长。schema与索引细节见数据库与系统设计.md。

旧定义缺 routingMode 按 legacy-v1；新草稿采用 exclusive-branches-v1，显式升级后发布到新快照。答案 schemaVersion 仍为1，不因路径算法变化批量升级。旧填写引用固定版本，统计读取正式答卷而非过程候选答案。

## 文档阅读顺序

使用者：README → 运行与操作指南。开发者：本文件 → 数据库与系统设计 → API说明 → 专属分支与模式升级说明 → 系统统一分支机制迁移。评阅者：第一阶段项目报告 → 测试用例与结果 → 前端专属分支接入验收 → 发布检查记录 → AI使用日志。

历史验收保留当时事实；最新前端接入记录已取代较早“待接入”状态。源码是当前版本，不需要原型目录、node_modules或dist随Git上传，按锁文件安装并构建即可。

当前前端不提供逐份升级按钮。旧兼容接口保留用于历史版本，当前统一机制和维护脚本见《系统统一分支机制迁移》。页面图文入口见《前端页面操作指南》，自动测试复现见《自动化测试执行指南》。

演示数据分为scripts/seed-manual.ts（默认seed，人工问卷9题）及scripts/seed.ts（seed:system，原系统样例）。人工源定义见docs/examples/manual-color-survey.json，记录见《人工测试数据与记录》，初始化回归见tests/manual-seed.ts。
